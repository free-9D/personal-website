这个网站从一个可部署的静态站点骨架开始，逐步加入笔记、思考、项目等内容类型，以及帮助读者查找和阅读内容的功能。下面按阶段记录目前的开发历程，便于之后回顾和继续维护。

## Phase 1：搭建并部署基础站点

项目使用 Astro、TypeScript、Tailwind CSS 和 Markdown/MDX 建立基础结构，完成首页、导航、页脚、About 和 404 页面，并配置 GitHub Pages Project Site 所需的 `site`、`base` 路径和 GitHub Actions 工作流。

首次部署时，GitHub Actions 的构建与部署任务均显示成功，页面地址采用 `https://用户名.github.io/personal-website/` 的 Project Site 形式。这个阶段验证了从代码推送到 GitHub Pages 发布的基本流程。

## Phase 2：建立内容模型与阅读页面

项目按内容类型建立笔记、思考和项目的内容集合与页面，使用 Markdown/MDX 撰写正文。文章页面逐步加入目录、标签、关联内容和阅读排版；项目页面则用于整理项目状态、说明和链接。模板和草稿过滤也纳入内容发布流程。

这一阶段也用一篇数据结构笔记探索了 MDX 可视化：十字链表和邻接多重表的示意图把顶点结点、边结点及其字段放进图中，作为复杂结构说明的内容示例。

## Phase 3：改善内容发现与发布质量

在已有内容页面上增加了标签与系列归档、客户端站内搜索、RSS、Sitemap 和基础 SEO 元信息。搜索索引、RSS、Sitemap 以及页面路由都按公开内容规则过滤草稿，并处理 GitHub Pages 的 `/personal-website/` 路径前缀。

图片处理也有了一个 Markdown 示例：图片与文章一起放在内容目录中，并演示替代文字、图注和相对路径写法。Phase 3 的本地验收覆盖了列表与详情、关联内容、标签和系列、草稿过滤，以及搜索索引、RSS 和 Sitemap 的输出。

## Phase 4：加入 Vlog 与更新记录

这一阶段建立了 Vlog 和更新记录的内容集合、列表与详情页面。Vlog 首版按已选定的 B 站平台保存 BV 号和可选分 P 序号，由页面据此构造播放器配置，并提供前往 B 站观看的链接作为替代入口。更新记录支持日期、可选版本与分类、变更摘要和 Markdown 正文。

Vlog 与更新记录的列表及公开详情路由已纳入 Sitemap，草稿过滤也通过本地构建检查。Phase 4 最终本地构建检查了 38 个文件，未报告错误、警告或提示，并生成了 36 个页面。

## 当前状态

Phase 1 至 Phase 4 的主要功能已在本地实现并完成相应构建验收。Phase 4 的验收使用的是内部草稿内容，没有发布真实 Vlog；真实 B 站视频的嵌入播放效果尚未验证。本轮开发也没有进行线上 GitHub Pages 部署检查。

后续可以根据实际写作和访问体验继续调整内容、页面与维护方式。Vlog、更新记录和其他内容是否公开，应在替换为已确认的真实内容后再决定。
