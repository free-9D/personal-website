## 硬布线&微程序控制

硬布线

优点：因为它是组合逻辑电路，硬件直接响应，因此它的速度快。
缺点：难以扩展，当指令非常多时硬件电路会非常庞大；不好修改，每次修改后都需要重新设计硬件电路逻辑，修改成本太高。

微程序控制

优点：灵活性高，可维护性强。
缺点：每条微指令需要从控制存储器中去读取，导致微指令的执行需要的微周期数增加，从而影响执行速度。


微程序控制执行过程

1、将指令中的OP部分提取出来，交给微程序控制器中。
2、由微地址形成部件生成微指令的地址交给uPC。
3、由uPC告知控制存储器要取的微指令的地址在哪，取哪条微指令，并将微指令交给uIR。
4、uIR通过读取微指令中微命令部分的内容执行操作，再将微指令中下地址部分的内容交给微地址形成部件。

## 最佳归并树（k 路归并）虚段计算公式

> m：**初始归并段数量**；k：归并路数
> 公式：
> 
> 
> $u=(m-1)\bmod(k-1)$
> 
> 
> 1. 如果 $\boldsymbol{u=0}$：**不需要虚段**，直接构造严格 k 叉哈夫曼树（最佳归并树）
> 2. 如果 $\boldsymbol{u\neq0}$：需要补充 $\boldsymbol{(k-1)-u}$ 个**虚段**（虚段权值 = 0）

> 
> 原理一句话：**最佳归并树必须是严格 k 叉树（每个分支结点都恰好有 k 个孩子）**。严格 k 叉树的叶子结点数量 $n_0$ 必须满足 $(n_0-1)\%(k-1)=0$。初始归并段就是叶子；不够就补权 = 0 的虚叶子（虚段）。

### 推导简单看（理解用，考试直接套公式）

严格 k 叉树的性质：

$n_0 = (k-1)n_k + 1$

$n_0$：叶子总数（真实段 + 虚段）；$n_k$：分支结点数目。

变形得到：$(n_0-1)$ 一定能被 $(k-1)$ 整除。

我们已有 m 个真实叶子。若 $(m-1)$ 除以 $(k-1)$ 有余数，就要补虚段，把总叶子数凑成满足这个整除条件的最小数。

## 线程概念考点的回顾

**进程**的诞生是为了解决多任务并发执行的问题，而**线程**的诞生是为了进一步降低并发执行的**开销**。

**线程**分为 **用户组线程** 与 **内核级线程** ：

* 用户级线程由用户空间的线程库进行创建与管理
* 内核级线程由内核空间的操作系统进行创建与管理

同一进程中的多个线程是共享进程资源的，但是线程的阻塞可能会导致其它线程也被阻塞，整个进程被挂起，为解决这个问题引入了**多线程模型**

* N对一模型，多个用户级线程对应一个内核级线程
  - 优点：线程切换在用户空间完成，开销小。
  - 缺点：线程阻塞会使用其它所有线程一起阻塞。
* 一对一模型：每个用户级线程都对应一个内核级线程
  - 优点：一个线程阻塞不会影响其它线程的执行，提升线程之间的并发性
  - 缺点：线程切换是在内核空间完成的，变成了内核级线程的切换，开销大
* N对M模型，N>=M,多个用户级线程对应一个内核级线程
  - 优点：是上面两种模型优点的折中型。

## B树的建造方法回顾

建造一个m阶的B树。

1. 将关键字按大小放在对应的结点中
2. 若结点中关键的数量超过了m-1，则将$\lfloor m/2 \rfloor$位置上的关键字提取出来，将其移至父结点中。
3. 当父结点中因2)移入新结点时，同样可能会发生2)的情况，直到B树稳定。

> K阶B树，最多有$m$棵子树，$m-1$个关键字，最少得有$\lceil m/2 \rceil$棵子树，$\lceil m/2 \rceil - 1$个关键字

## 处理器类型及相关问题

单周期CPU：
* CPI为1
* 时钟周期由执行时间最长的那条指令来决定
* 时钟频率低

多周期CPU：
* CPI一般都大于1
* 指令被拆分成多个阶段，每个阶段一个周期
* 时钟频率会高一点
* 时钟周期由各个阶段中执行时间最长的时间来决定
* 依旧是串行执行指令，没有并行

基本流水线CPU：
* 理想无阻塞的情况下，CPI为1
* 可并行执行指令
* 会有**冒险**问题

超标量流水线CPU：
* 比流水线不同的是，每个阶段可以有多个相同的部件并行执行，以加快指令的执行速度

## 中断处理与中断响应优先级的概念

当中断来临，首先会由中断屏蔽字来觉得响应哪个中断，通过中断屏蔽字的筛选后，再由中断判优机构来决定处理哪个中断。（我的回忆，这是错误的）

正确版：
### 1. 中断判优机构（硬件判优：中断排队电路）

**发生时机：多个中断源同时发中断请求 IR 的时候**
作用：**选出优先级最高的那个中断请求**，把它送到 CPU 的中断请求输入端。

- 硬件判优：链式排队电路、独立请求总线判优。
- 判优只做一件事：**多个中断同时到来，谁优先级高，谁获得请求信号**。

> 
> 判优，是**选择哪个中断请求被提交给 CPU**。

### 2. 中断屏蔽字（中断屏蔽寄存器 IMR）

**发生时机：CPU 准备响应中断的时候（或者中断服务程序内部）**
中断屏蔽字每一位对应一个中断源：

- 屏蔽位 = 1：屏蔽，这个中断就算来了，也不能打断当前执行；
- 屏蔽位 = 0：开放，可以响应。

核心：**屏蔽字决定：当前 CPU 环境下，能不能响应这个中断**。
屏蔽字可以动态修改！这就是**动态改变中断优先级**的原理。

> 
> 屏蔽字不是用来 “挑选多个中断里谁优先级最高”，而是**控制是否允许该中断打断现场**。

> 我的总结就是：中断->中断判优->中断屏蔽字。
>
> 中断判优，决定中断请求信号归谁。在**同一时刻有多个中断源同时发请求**的时候，从这一堆请求里，**选出硬件静态优先级最高的那一个中断源**，产生一个**送到 CPU 的公共中断请求信号 INTR**。
>
> 中断屏蔽字，决定当前CPU处理哪个中断

## 乘法运算的实现

> 核心本质：乘法 = 加法 + 移位

无符号乘法（原码一位乘法，仅绝对值运算）
✅适用：无符号数、原码数值位相乘；符号位单独异或
寄存器：A (部分积，初 0)、B (被乘数)、Q (乘数)，A+Q 存 2n 位结果
循环 n 次（n = 数值位位数）

1. 看 Q 最低位$Q_0$
   - $Q_0=1$：A = A + B
   - $Q_0=0$：A 不变
2. A、Q 联合【逻辑右移】
结束：A 存乘积高 n 位，Q 存乘积低 n 位
考点短句：逻辑右移；只看 1 位；无符号；循环 n 次；符号单独处理

有符号乘法（Booth 补码乘法，大题重点）
✅适用：补码有符号数，符号位直接参与运算，无需单独求符号
寄存器：A (部分积，初 0)、Q (乘数)；乘数增设附加位$Y_{n+1}$，初始为 0
循环 n 次

1. 判断 Q 末位$Y_n$和附加位$Y_{n+1}$（两位）
   - 00、11：不加
   - 01：A += $[X]_{补}$
   - 10：A += $[-X]_{补}$
2. A、Q、附加位一起【算术右移】
考点短句：算术右移；看末尾两位 + 附加位；有符号补码；循环 n 次

阵列乘法器（选择题｜并行乘法）

- 无符号并行乘法，组合逻辑电路，无循环移位，速度最快，硬件开销大
- n 位 ×n 位 → 输出 2n 位乘积

## 树的路径长度相关概念（包含哈费曼树）

1. **WPL（带权路径长度）**：$\boldsymbol{WPL=\sum w_i l_i}$
   - $w_i$：叶子权值（**频次，不是概率**）
   - $l_i$：根到叶子的路径边数 = 哈夫曼编码的码长
   - 含义：**总比特数**。如果权是各个字符出现多少次，WPL 就是把整篇文本编码完一共多少位。
  > 一句话：WPL = **总和**
2. **哈费曼树的加权平均长度**：$\bar L=\frac{\sum w_i l_i}{\sum w_i}=\frac{\text{WPL}}{\text{总频次}}=\sum p_i l_i$
   1. 这里 $p_i=\dfrac{w_i}{\sum w_i}$，是字符出现概率。
   > 一句话：加权平均码长 = **平均每个字符占多少比特**
   > 对应真题，2023年真题，题4
3. **路径长度**：用于配合 WPL 定义和哈夫曼编码（如 "等长 vs 变长编码总长度"）。根到第K层的结点，它的路径长度就是K-1
4. **ASL 与路径长度的关系**：二叉排序树查找成功 ASL = 各结点路径长度之和 /n（等价于平均比较次数），这是查找章节的高频考点

## CSMA/CD的二进制指数退避算法

假设冲突发生了k次

> 前提：以太网CSMA/CD，发生冲突之后执行退避，**争用期（时隙）= 2τ**

假设冲突发生了 k 次：

1. 随机等待争用片的个数范围是 $\boldsymbol{[0,\;1,\;2,\;3,\dots,\;2^k - 1]}$
   - 从这个整数集合里**等概率随机选一个数 r**
   - 实际等待时间：$\boldsymbol{r \times 争用期}$
2. 注意 k 有上限：$\boldsymbol{k=\min(实际冲突次数,\;10)}$
   - 冲突次数 ≤10：k 等于冲突次数，区间上限 $2^k-1$ 随冲突次数指数变大
   - 冲突次数 11~15：k 固定取 10，上限固定为 $2^{10}-1=1023$，不再继续放大
3. 最多冲突**16 次**：连续冲突达到 16 次，直接丢弃该帧，向上层报告发送失败

**若是题目中没有给出争用期（时隙）的大小，则可以通过下面的方法来求：**

争用期（时隙 slot time） = $\boldsymbol{2\tau}$
$\tau$：**单程最大传播时延**
$\tau = \frac{\text{总线最大长度} \ L}{\text{信号传播速率} \ v}$
$\boldsymbol{\text{争用期}=2\tau=\dfrac{2L}{v}}$

> 
> 含义：信号从一端跑到另一端是 $\tau$；冲突信号跑回来被发送方感知到，来回一趟就是 $2\tau$。
> CSMA/CD 规定：**时隙 = 2τ**，发送方必须在 $2\tau$ 之内收到冲突信号。

## 各协议的最终检验和计算方法

拿UDP举例：

UDP 校验和是**16 位二进制反码求和**：

1. 把所有 16bit 分组做**反码加法**（按位加，有进位就把进位加到最低位，回卷进位）
2. 全部加完之后，**对总和按位取反**，才是 UDP 校验和

**完整四步流程（默写版）**

1. 构造伪首部（拿 IP 头里的源 IP、目的 IP、协议号、UDP/TCP 长度组装）
2. 把【伪首部 + UDP/TCP 头 + UDP/TCP 数据】拼接起来；奇数末尾补 0，对齐 16bit
3. 所有 16bit 分组依次做**反码加法**，溢出的最高进位回卷加到最低位
4. 全部累加完成后，对总和按位取反 → 这个结果就是校验和

## BGP协议

BGP协议分为外部BGP（eBGP）和内部BGP（iBGP）

BGP的报文类型：

- OPEN（打开）报文：用来和相邻的BGP区域边界路由器建立关系，进行通信初始化。
- UPDATE（更新）报文：用来通告路由器，以及列出需要更新的多条路由。
- KEEPALIVE（保活）报文：用来周期性的证实临站的连通性。
- NOTIFICATION（通知）报文：用来发送检测到的差错。

**BGP路由选择**

1. 根据偏好值：通常由路由器管理员来设定，会考虑经济、政治因素。
2. AS跳数最少：就是经过的AS自治系统数量最少。
3. 热土豆算法：就是最快逃离当前AS自治系统的路径。
4. AS边界路由器标识符最小：通常标识符最小的路由器最老，老的肯定比小的能干。标识符通常是由路由器的接口中IP地址最大决定。发送BGP报文时路由器之间会相互告之路由器的ID。

SSD无寻道，页读块擦，磨损均衡在固件；

**易混坑清单**
1. ❌ 磨损均衡不是操作系统/文件系统做的，是SSD控制器固件
2. ❌ 文件系统不能减少SSD寻道时间，SSD根本没有寻道

4. ❌ 低级格式化划分扇区，高级格式化是文件系统建分区、确定盘块、建FS
