个人感觉Emacs其实是各种高效编辑快捷键的一个集合体，支持的功能有：

* 一个字符一个字符的移动
* 一个单词一个字词的移动
* 一个句子一个句子之间的移动
* 一个段落一个段落的移动
* 选中文本内容
* 复制、粘贴、剪切
* 可以撤消错误命令
* 可以回滚剪贴板的内容【*】
* 有主模式（major mode）与辅助模式（mini mode）之分【*】
* 可以使用dired管理文件，在dired 模式下还可以像编辑文本一样去修改文件名称【*】
* 它还内置很多shell的功能【*】
* 可以使用diff比对文件内容之间的差异【*】
* 还原生支持文件历史版本回溯【*】
* 自定义能力超强，使用elisp语言可以自己编辑想要插件功能【*】

```bash
M-y 回滚剪贴板
C-M-s 使用regexp进行搜索
M-x replace-regexp 使用regexp来进行替换操作
M-x re-building 测试你的regexp式子
M-x M-q 将原本只读的dired模式变成可以编辑的dired模式
```

## 主模式

`cua mode`一个矩形编辑模式，不过我感觉不好用，我会找其它工具来替代，具体命令可以网上去搜索

## 辅助模式

一般是依托于主模式的，是对主模式功能的一种补充或者加强。

## 帮助

```bash
C-h i 帮助手册的使用方法
C-h f Emacs命令（即你使用Alt-x后，输入的命令)解释
C-h a 可以模糊搜索自己想要的命令
```

## Tips

`*Message*`这个buffer里面存储的是底下缓冲区里的输出信息，挺有用的。
