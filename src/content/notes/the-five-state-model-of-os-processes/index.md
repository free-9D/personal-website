> 5 个状态：**新建态、就绪态、运行态、阻塞态（等待态）、终止态**
> 核心记忆：只有**就绪态**能进运行态；运行态可以主动 / 被动切到其他状态。

## 1. 新建态（New）

**作用**：进程刚被创建，操作系统正在分配资源、建立 PCB（进程控制块），还没准备好投入运行。
**操作**

1. 操作系统创建 PCB
2. 分配内存、建立地址空间
3. 初始化进程信息（程序计数器、寄存器等）
4. 资源准备完成 → 转入**就绪态**

> 
> 限制：系统负载高时，新建态进程会暂时停留，不进入就绪队列。

## 2. 就绪态（Ready）

**作用**：进程**已经获得除 CPU 以外所有资源**，等待 CPU 调度，一旦分配 CPU 就可以马上执行。
**操作**

1. 进程在就绪队列排队
2. 调度程序选中该进程 → 转入**运行态**
3. 运行态进程时间片用完，回到就绪态
4. 阻塞进程等待事件完成后，唤醒，进入就绪态

> 
> 特点：就绪进程不占用 CPU，只等调度。

## 3. 运行态（Running）

**作用**：进程正在 CPU 上执行指令。单 CPU 系统同一时刻最多只有 1 个进程处于运行态。
**操作（三种转出方向）**

1. **时间片耗尽** → 回到就绪态（被动，时钟中断）
2. **请求 I/O 或等待某事件（如等待信号量）** → 进入阻塞态（主动）
3. **进程正常结束 / 异常终止** → 进入终止态

## 4. 阻塞态 / 等待态（Blocked / Waiting）

**作用**：进程**主动放弃 CPU**，等待某个事件完成（磁盘 I/O、键盘输入、信号量、子进程返回等），此时就算 CPU 空闲也不能运行。
**操作**

1. 进程发起 I/O 或等待事件，主动进入阻塞队列
2. 等待的事件发生（I/O 完成、收到信号）→ 被操作系统唤醒，转入**就绪态**

> 
> ❗重点：阻塞态**不能直接进入运行态**，必须先进就绪队列排队。

## 5. 终止态（Terminated / Exit）

**作用**：进程执行完毕，或异常退出，操作系统保留 PCB 暂存信息，等待父进程回收资源。
**操作**

1. 释放大部分占用资源（内存、打开文件）
2. PCB 保留，保存退出码、运行统计信息
3. 父进程调用 wait () 回收 PCB → PCB 彻底销毁，进程消失

# 状态转换图（文字版）

新建态 → 就绪态 → 运行态
运行态 → 就绪态（时间片到）
运行态 → 阻塞态（等待事件）
运行态 → 终止态（结束）
阻塞态 → 就绪态（事件完成唤醒）

# 408 易混考点小结

1. 就绪→运行：**调度程序**触发
2. 运行→就绪：**时间片中断**
3. 运行→阻塞：**进程自身系统调用（主动）**
4. 阻塞→就绪：**中断处理程序唤醒**（不是进程自己唤醒）
5. 阻塞态**不会直接到运行态**
