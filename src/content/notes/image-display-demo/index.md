> 这是一篇用于预览网站图片排版的演示笔记，不包含个人经历。确认效果后，可以把需要的写法复制到自己的笔记中。

## 正文中的本地图片

Markdown 图片语法是 `![替代文字](图片路径)`。下面的图片文件放在这篇笔记自己的 `assets` 目录中，路径相对于当前 Markdown 文件：

![一张示意图：图片文件随笔记存放，经过构建后展示在正文内容区域中](./assets/reading-flow.svg)

*图：本地图片从文章资源目录进入正文；图片会随站点一起构建。*

给图片写清楚替代文字，读屏软件可以据此描述图片；当图片无法加载时，页面也会显示这段文字。图注则用普通 Markdown 斜体段落即可。

## 写作时可以复制的格式

```md
![简洁描述图片主要信息的替代文字](./assets/图片文件名.webp)

*图：补充说明图片来源、重点或上下文。*
```

文章目录结构可以这样组织：

```text
src/content/notes/你的笔记目录/
├── index.md
└── assets/
    └── 图片文件名.webp
```

图片文件名建议体现用途，例如 `architecture.svg`、`screen-home.webp`。如果图片来自他人，请在图注或正文标明来源；正式发布前也要确认图片可以公开使用。

## 预览说明

这篇示例采用本地 SVG，以便离线也能预览。正文中的图片会保持自适应宽度，不会超出阅读栏；具体显示尺寸会随阅读区域变化。
